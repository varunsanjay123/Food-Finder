# 🍽️ Food Finder

A simple food search web application built using **HTML, CSS, and jQuery** for learning API integration. This project uses the **TheMealDB API** to fetch and display meal information in real time.

## 🚀 Features

- 🔍 Search meals by name
- 📷 Display meal image and title
- 🥗 View ingredients
- 📖 Read cooking instructions
- 📱 Responsive user interface

## 🛠️ Tech Stack

- HTML5
- CSS3
- jQuery
- TheMealDB API

## 🔗 API

The data is provided by **TheMealDB**.

https://www.themealdb.com/api.php
